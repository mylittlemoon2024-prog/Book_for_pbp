# Book Club Bot

Telegram-бот для записи участников книжного клуба на встречи. Список встреч
и записи хранятся в Google-таблице — не нужна отдельная база данных, всё
видно и редактируется вручную.

## Возможности

- 📅 Показывает список ближайших встреч (по дате, из листа `Meetings`).
- ✅ Запись на встречу с указанием имени и телефона.
- ❌ Отмена своей записи — доступна не позднее чем за 24 часа до встречи
  (`CANCELLATION_CUTOFF_HOURS` в `bot/services/sheets.py`); ближе к дате
  кнопка отмены пропадает и карточка встречи объясняет, что срок истёк.
- 📝 Просмотр своих активных записей (`Мои записи`).
- Учитывает вместимость встречи (`capacity`), если она задана.
- 📚 «Выбрать книгу»: выбор жанра → случайная книга с фото, автором,
  названием и описанием (из листа `Books`).
- 🎓 «Лекции»: выбор направления → случайная лекция со ссылкой на видео
  (YouTube/VK/Rutube — открывается вовне, из листа `Lectures`).
- ℹ️ «О проекте»: рассказ о боте и клубе, с возможностью оставить
  предложение (имя + текст сохраняются в лист `Suggestions`).
- 🤝 «Контактная информация»: контакты по сотрудничеству и по техническим
  вопросам работы бота.

## 1. Создать бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Придумайте имя и username бота.
3. Получите токен вида `123456789:AA...` — он понадобится в `.env`.

## 2. Подготовить Google-таблицу

1. Создайте новую Google-таблицу.
2. Скопируйте её ID из URL:
   `https://docs.google.com/spreadsheets/d/<ЭТОТ_ID>/edit`.
3. Бот сам создаст листы `Meetings` и `Registrations` с нужными заголовками
   при первом запуске, если их ещё нет. Можно создать их заранее вручную —
   структура такая:

   **Meetings**

   | id | title | date | time | location | capacity | description |
   |----|-------|------|------|----------|----------|--------------|
   | 1 | Обсуждаем «Мастер и Маргарита» | 2026-08-20 | 19:00 | Кафе «Буквы», ул. Ленина 5 | 15 | Приходите с вопросами! |

   `date` — бот понимает и `2026-09-13`, и `13.09.2026` (Google Sheets всё
   равно переформатирует дату по локали таблицы, так что жёстко следовать
   одному формату не обязательно — просто убедитесь, что Google Sheets
   действительно распознал текст как дату, а не оставил его обычным
   текстом). `capacity` можно оставить пустым — тогда лимита мест не будет.

   **Registrations** — заполняется ботом автоматически, трогать не нужно.

   **Books**

   | id | genre | title | author | description | photo_url | age_rating |
   |----|-------|-------|--------|--------------|-----------|------------|
   | 1 | Фантастика | Дюна | Фрэнк Герберт | Юный Пол Атрейдес оказывается втянут в борьбу за пустынную планету Арракис — единственный источник ценнейшего во вселенной вещества. | https://example.com/dune.jpg | 16+ |

   `genre` — должен **точно** совпадать (включая регистр) с одним из
   12 фиксированных жанров, которые бот показывает в меню «Выбрать книгу»
   (список задан в коде, `bot/services/sheets.py`, константа `GENRES`):

   Проза · Фантастика · Детектив и триллер · Ужасы и мистика · Любовный
   жанр · Приключения · Драма и трагедия · Юмор и сатира · Поэзия ·
   Драматургия · Для детей · Нон-фикшн

   Книга с любым другим значением в `genre` просто не попадёт ни в одну
   кнопку меню. `photo_url` — прямая ссылка на изображение обложки (можно
   взять с Google Images, Goodreads и т.п.); если оставить пустым, бот
   пришлёт карточку без фото. Можно добавлять сколько угодно книг в один
   жанр — бот каждый раз показывает случайную, с кнопкой «Другая книга»
   для новой попытки.

   `age_rating` — российская возрастная маркировка книги: `0+`, `6+`,
   `12+`, `16+` или `18+` (любое другое значение бот проигнорирует, как
   будто поле пустое). Если заполнено, метка показывается прямо в
   карточке книги рядом с названием (для `18+` — с 🔞).

   **Lectures**

   | id | category | title | speaker | description | video_url |
   |----|-----------|-------|---------|--------------|-----------|
   | 1 | Психология | Как работает мотивация | Иван Иванов | Разбираем, почему мы откладываем дела на потом. | https://youtube.com/watch?v=... |

   `category` — должен **точно** совпадать с одним из 8 фиксированных
   направлений, которые бот показывает в меню «Лекции» (список задан в
   коде, `bot/services/sheets.py`, константа `LECTURE_CATEGORIES`):

   Литература и писательство · Психология · История · Философия ·
   Саморазвитие · Искусство и культура · Наука · Мотивация и карьера

   `video_url` — ссылка на видео (YouTube, VK Видео, Rutube и т.п.), бот
   присылает её текстом, само видео не загружает и не хранит. Можно
   добавлять сколько угодно лекций в одно направление — бот каждый раз
   показывает случайную, с кнопкой «Другая лекция» для новой попытки.

   **Suggestions** — заполняется ботом автоматически (имя, текст
   предложения, Telegram user_id, username, дата), трогать не нужно.

## 3. Дать боту доступ к таблице (сервисный аккаунт Google)

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/),
   создайте проект (или используйте существующий).
2. Включите **Google Sheets API** для проекта (APIs & Services → Enable APIs
   → найти "Google Sheets API" → Enable).
3. Создайте сервисный аккаунт: APIs & Services → Credentials → Create
   Credentials → Service account.
4. Откройте созданный аккаунт → Keys → Add Key → Create new key → JSON.
   Скачается файл — сохраните его в проекте как `credentials.json`.
5. Скопируйте email сервисного аккаунта (вида
   `xxx@xxx.iam.gserviceaccount.com`) и откройте им доступ **Редактор** к
   вашей Google-таблице (кнопка «Настройки доступа» в таблице).

## 4. Настроить окружение

```bash
cp .env.example .env
```

Заполните `.env`:

```
BOT_TOKEN=<токен от BotFather>
SPREADSHEET_ID=<ID таблицы>
GOOGLE_CREDENTIALS_PATH=credentials.json
```

Положите скачанный `credentials.json` в корень проекта (файл уже в
`.gitignore`, в репозиторий он не попадёт).

## 5. Запуск

### Локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

### Через Docker

```bash
docker compose up --build -d
```

Бот работает в режиме long polling — специальный хостинг с публичным URL не
нужен, подойдёт любой сервер/VPS/PaaS (Railway, Render, Fly.io и т.п.), где
можно оставить процесс работающим постоянно.

### На Railway (постоянный хостинг)

1. Зайдите на [railway.app](https://railway.app/), войдите через GitHub.
2. **New Project** → **Deploy from GitHub repo** → выберите репозиторий
   `Book_for_pbp`. Railway сам найдёт `Dockerfile` и соберёт образ — ничего
   дополнительно настраивать не нужно.
3. Откройте сервис → вкладка **Variables** → добавьте переменные:

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `SPREADSHEET_ID` | ID таблицы |
   | `GOOGLE_CREDENTIALS_JSON` | содержимое `credentials.json` целиком (весь JSON-файл как одна строка/блок) |

   Файл на Railway не примонтировать, поэтому здесь используется
   `GOOGLE_CREDENTIALS_JSON`, а не `GOOGLE_CREDENTIALS_PATH` — бот сам
   поймёт, что использовать.
4. Сохраните — Railway задеплоит и запустит бота. При падении процесс
   перезапускается автоматически, отдельно ничего поддерживать не нужно.

## Структура проекта

```
bot/
  main.py              — точка входа, запуск polling
  config.py             — чтение .env
  states.py             — FSM-состояния формы записи
  keyboards.py          — инлайн-клавиатуры
  handlers/
    start.py            — /start, главное меню
    registration.py     — список встреч, запись/отмена, "мои записи"
    books.py             — каталог книг: жанры → случайная книга
    lectures.py           — каталог лекций: направления → случайная лекция
    about.py             — "О проекте", "Контактная информация", форма предложений
  services/
    sheets.py            — работа с Google Sheets (gspread)
```

## Обновить контакты

Текст раздела «Контактная информация» — константа `COOPERATION_TEXT` в
`bot/handlers/about.py`. Поменяйте текст и задеплойте новую версию
(изменения кода на Railway применяются автоматически при пуше в
подключённую ветку).
